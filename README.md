# mzdy

An administration tool for an outpatient clinic (ambulance). Scope is not yet
defined; this is the scaffold only.

Stack: Next.js 16 (App Router) + shadcn/ui + Tailwind v4, TypeScript, Biome.
No database or server-side code yet.

## Run

```sh
nvm use
npm install
npm run dev      # http://localhost:3000
```

```sh
npm run typecheck
npm run lint
npm run build
```
